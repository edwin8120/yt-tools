プライバシーポリシー

最終更新日：2026年11月17日

yt-tools（以下「本ツール」）は、YouTubeチャンネルの運営者が、自分のチャンネルのためだけに使う個人用ツールです。

1. 利用するデータ

本ツールは、運営者本人が許可したGoogleアカウントについて、YouTube Data API と YouTube Analytics API を通じて次の操作を行います。

  • 運営者が制作した動画・サムネイル・説明文を、運営者のチャンネルにアップロードする
  • 運営者のチャンネルと動画の統計（再生回数、視聴時間、流入元など）を読み取る

2. データの保存

認証情報と取得した統計は、運営者のパソコンにのみ保存します。外部のサーバーには保存しません。

3. 第三者への提供

取得したデータを第三者に販売・提供・共有することはありません。

4. Google API サービスの利用

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（Limited Use 要件を含む）に従います。YouTube API サービスの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

5. アクセス権の取り消し

本ツールへのアクセス権は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の Issues からお願いします。

Privacy Policy (English summary)

yt-tools is a personal tool used only by its owner. Using the YouTube Data API and YouTube Analytics API, it uploads the owner's own videos to the owner's channel and reads the owner's own channel statistics. Credentials and data are stored only on the owner's computer and are never sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: GitHub Issues of this repository.
